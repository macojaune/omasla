# beUI Native dans Omasla

Composants copiés du [registre beUI Native](https://github.com/starc007/beui-native) avec la CLI `beui-native@0.1.0`, sous [licence MIT](./LICENSE). Le code est embarqué dans l’app et les couleurs jour et nuit sont définies dans [global.css](../../global.css), en cohérence avec la palette des éléments cartographiques.

Le champ `Input` accepte la hauteur et le contraste du champ de recherche d’Omasla. Les contrôles partagés de l’application sont raccordés dans [theme/ui.tsx](../theme/ui.tsx).
